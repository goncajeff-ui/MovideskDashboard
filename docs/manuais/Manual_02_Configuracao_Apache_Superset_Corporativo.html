Plataforma: Apache Superset 6.1.0 (WSL2) Fonte de Dados: SQL Server (MovideskDM) Porta Padrão: 8088 (HTTP / Ngrok HTTPS)

04

Capítulo 01

Conectando o Banco de Dados (MSSQL MovideskDM)

Passo a Passo Mastigado para Plugar o Microsoft SQL Server no Apache Superset

Com o Apache Superset iniciado pelo Painel de Controle (Online na porta 8088), o primeiro passo é cadastrar a conexão com o banco de dados MovideskDM que roda no seu SQL Server local. Siga exatamente o roteiro abaixo:

1
Acessar a Tela de Conexões: Abra o navegador em http://localhost:8088, entre com seu login de administrador (padrão: admin / admin). No canto superior direito, clique no ícone de engrenagem Settings (⚙️) e selecione a opção Database Connections.
2
Iniciar Nova Conexão: Clique no botão azul + Database (canto superior direito). Na janela modal que abrir, na lista SUPPORTED DATABASES, selecione Microsoft SQL Server.
3
Preencher Nome e String SQLAlchemy URI: No campo DISPLAY NAME, digite MovideskDM. No campo SQLALCHEMY URI, informe a string abaixo (substituindo 172.29.112.1 pelo IP do seu Windows visto pelo WSL2, ou mantendo o IP já configurado):
mssql+pymssql://sa:123456@172.29.112.1:1433/MovideskDM
4
Testar e Salvar: Clique no botão Test Connection. O Superset exibirá uma mensagem verde no canto inferior direito: "Connection looks good!". Em seguida, clique em Connect para finalizar.
Elemento da URI Valor Exemplo Explicação Didática ("Mastigada")
Driver Dialeto mssql+pymssql:// Indica ao Superset que deve usar o driver Python pymssql (já instalado na venv do WSL2).
Credenciais SQL sa:123456 Usuário e senha do SQL Server (mesmos configurados no appsettings.json do Painel).
Host e Porta TCP @172.29.112.1:1433 IP do host Windows na ponte WSL2 e porta padrão do MSSQL. (Para ver o IP no WSL: ip route | awk '/default/ {print $3}').
Nome do Banco /MovideskDM Nome exato do Data Mart criado pelos scripts SQL do projeto.

Capítulo 02

Mapeamento de Datasets (Expondo as Views do Schema mart)

Como Transformar as 8 Views Analíticas do SQL Server em Fontes de Dados para os Gráficos

No Apache Superset, os gráficos não leem tabelas diretamente: eles consomem Datasets. Toda a inteligência de negócio da Advice (cálculo de SLA, conversão para Horário de Brasília, faixas de Aging e vínculo de Empresas) já está pronta dentro do schema mart no banco MovideskDM. Basta registrar cada uma das 8 Views seguindo o passo a passo abaixo:

1
Abrir o Cadastro de Datasets: Na barra de navegação superior do Superset, clique em Datasets e, no canto superior direito, clique no botão + Dataset.
2
Selecionar Banco, Schema e View: Na lateral esquerda, preencha os 3 seletores na ordem:
• Em DATABASE: selecione MovideskDM.
• Em SCHEMA: selecione mart (muito importante: não use raw nem core nos gráficos).
• Em TABLE: escolha a View desejada (comece por vw_VisaoGeralKpis).
3
Salvar o Dataset: Clique no botão inferior direito Create Dataset and Create Chart (ou apenas Create Dataset). Repita o processo para as 8 Views listadas na tabela abaixo — leva menos de 2 minutos para cadastrar todas!
View no Schema mart Coluna de Tempo O que esta View entrega pronta para o Dashboard
mart.vw_VisaoGeralKpis Snapshot Atual Big Numbers por Equipe: BacklogAtual, SlaVencidos, SlaIminente4h, SlaPausados, EmDependenciaDev, AbertosHoje, ResolvidosHoje e FcrUltimos30DiasPct.
mart.vw_SlaRadar DataCriacao Fila aberta classificada por risco de SLA (Vencido, Crítico < 2h, Alerta < 4h) com nome da Empresa, Analista e MinutosParaVencer.

Capítulo 03

Criação de Gráficos (Sala de Guerra & Big Numbers)

Tutorial Passo a Passo ("Mastigado") para Criar um Card Big Number Arrastando Métricas

A Sala de Guerra tem no seu topo os indicadores executivos instantâneos (Big Numbers). Veja abaixo como criar passo a passo o cartão de Backlog Atual (Chamados em Aberto) arrastando a métrica da view mart.vw_VisaoGeralKpis:

1
Iniciar Novo Gráfico: No menu superior, clique em Charts → botão + Chart. Em Choose a dataset, selecione vw_VisaoGeralKpis. Na galeria de tipos (KPI), clique em Big Number e depois no botão azul Create New Chart.
2
Arrastar a Métrica para o Campo METRIC: Na coluna esquerda da tela de edição (Columns), localize a coluna numérica BacklogAtual. Clique e arraste-a para dentro da caixa METRIC (na aba central DATA). Na janelinha que abrir, na aba SIMPLE, confirme o agregador SUM (Soma) e clique em Save.
3
Definir Subtítulo e Formatação: No campo SUBHEADER, digite Chamados Ativos na Fila. Clique na aba CUSTOMIZE (ao lado de DATA) e em Number format selecione ,d (exibe inteiro sem casas decimais). Clique em Update chart para ver o número gigante na tela!
4
Salvar no Dashboard: Clique no botão superior direito Save. Em CHART NAME, digite KPI - Backlog Atual. Em ADD TO DASHBOARD, digite/selecione Sala de Guerra Movidesk e clique em Save & go to dashboard.
Gráfico da Sala de Guerra Dataset (Schema mart) Tipo no Superset O que arrastar para Metric e Dimensions
1. Cards Topo (Backlog, SLA Vencido, Crítico < 4h) vw_VisaoGeralKpis Big Number Metric: SUM(BacklogAtual), SUM(SlaVencidos), SUM(SlaIminente4h) (1 card para cada).
2. Evolução Diária da Fila (90 dias) vw_BacklogEvolucao Time-series Area Chart Time Column: DataSnapshot | Metric: SUM(QtdTickets) e SUM(QtdSlaVencido).
3. Termômetro Preditivo de SLA (Fila Viva) vw_SlaRadar Table Dimensions: TicketId, Cliente, Assunto, Analista, FaixaRiscoSla, MinutosParaVencer.
4. Gargalos por Status (Onde o ticket para) vw_StatusAging Bar Chart (Horizontal) Dimensions: Status | Metric: AVG(HorasUteisMedias).
5. Radar de Clientes Silenciosos (Churn) vw_ClienteRaioX Table Dimensions: Cliente, StatusRelacionamento, DiasDesdeUltimoTicket, SlaCumpridoPct.

Capítulo 04

Gestão de Acessos (Perfil da Diretoria com Role "Gamma")

Como Criar Usuários Somente Leitura (Visualização de Dashboards sem Permissão de Edição)

A Diretoria e os gestores executivos precisam consultar os indicadores, aplicar filtros de período/equipe e exportar relatórios, mas não devem alterar a estrutura dos gráficos nem executar comandos SQL. No Apache Superset, esse controle é feito combinando a Role nativa Gamma (consumidor apenas leitura) com a permissão de leitura sobre o banco MovideskDM:

1
Liberar Leitura do Banco MovideskDM para o Perfil Gamma (1 única vez): No canto superior direito, clique em Settings (⚙️) → List Roles. Na linha da role Gamma, clique no ícone de lápis (Edit Record). No campo Permissions, digite e adicione a permissão database access on [MovideskDM] (ou all database access on all_database_access) e clique em Save. Isso garante que o usuário Gamma veja os gráficos do MovideskDM sem receber erro de acesso negado à fonte de dados!
2
Abrir o Cadastro de Usuários: Clique novamente em Settings (⚙️) → List Users e clique no botão + (Add User) no canto superior direito.
3
Preencher os Dados do Executivo e Atribuir a Role "Gamma":
• First Name / Last Name: Ex.: Diretoria / Advice | User Name: diretoria.advice
• Is Active: Marque a caixa ☑ | Role: Selecione exclusivamente Gamma.
• Password / Confirm Password: Defina uma senha forte e clique em Save.
4
Publicar o Dashboard (Published): Na tela do Dashboard Sala de Guerra Movidesk, certifique-se de que a tag ao lado do título está como Published (e não Draft). Usuários Gamma só enxergam dashboards publicados!
Role do Superset Público-Alvo na Advice O que pode fazer / O que está bloqueado
Gamma Diretoria, Executivos e Clientes Pode: Visualizar dashboards publicados e usar filtros.
Bloqueado: Editar gráficos, excluir painéis, abrir SQL Lab ou mexer em conexões.
Alpha Analistas de BI / Coordenadores Pode criar e editar gráficos e dashboards, mas não pode alterar permissões de outros usuários.
Admin Engenharia / Administradores Controle total sobre conexões de banco, usuários, roles e configurações do servidor.

Capítulo 05

Publicação Externa Segura (Túnel Reverso com Ngrok)

Passo a Passo Mastigado para Expor a Porta 8088 em um Link HTTPS Público para Diretoria / Cliente Final

Como o Apache Superset roda localmente na sua máquina na porta 8088, o utilitário ngrok permite criar instantaneamente um túnel reverso criptografado (HTTPS/TLS) sem precisar abrir portas no roteador/firewall da empresa. Siga o roteiro mastigado abaixo:

1
Criar Conta Gratuita e Copiar o Authtoken (Só na 1ª vez): Acesse https://dashboard.ngrok.com, crie sua conta gratuita e, no menu lateral esquerdo, clique em Your Authtoken. Copie o token exibido na tela.
2
Instalar e Autenticar o Ngrok: No Windows (via PowerShell ou CMD), instale o ngrok com winget install Ngrok.Ngrok (ou baixe o executável no site oficial) e registre seu token uma única vez com o comando:
ngrok config add-authtoken COLE_SEU_TOKEN_AQUI
3
Iniciar o Superset e Abrir o Túnel na Porta 8088: Primeiro, certifique-se no MovideskControlPanel.exe de que o Superset está Online na porta 8088. Em seguida, execute no terminal o comando abaixo:
ngrok http 8088 --host-header="localhost:8088"
4
Copiar o Link Público HTTPS Gerado: O ngrok abrirá um painel de status no terminal. Localize a linha Forwarding, copie o endereço que começa com https:// (ex.: https://a1b2-200-150-10-20.ngrok-free.app) e envie para a Diretoria acessar usando o usuário Gamma criado no Capítulo 04!
Dica de Segurança Corporativa (Dupla Camada de Senha): Se desejar exigir uma senha extra do próprio túnel antes mesmo de carregar a tela de login do Superset, adicione o parâmetro --basic-auth ao comando:
ngrok http 8088 --host-header="localhost:8088" --basic-auth="advice:SenhaExecutiva2026"
Comando Ngrok Quando Utilizar e O Que Ele Faz
ngrok http 8088 --host-header="localhost:8088" Padrão Recomendado: Cria túnel HTTPS público apontando para o Superset local na porta 8088 reescrevendo o cabeçalho Host para evitar bloqueios de CSRF.
ngrok http 8088 --basic-auth="usuario:senha123" Alta Segurança: Exige autenticação HTTP Basic na borda da nuvem do ngrok antes de entregar a tela de login do Superset.
ngrok http 8088 --url=seu-dominio.ngrok-free.app URL Fixa Gratuita: Usa o domínio estático gratuito fornecido na aba Domains do painel do ngrok para que o link nunca mude ao reiniciar.
